## 固定报告未校验请求提供的 SHA-256

触发输入为 A06 的固定报告，在报告末尾追加换行并继续提交原哈希。旧 pipeline 在读取 fixed_report 时直接解析 JSON，未消费 fixed_report_sha256，内容变化可能进入修复阶段。该缺陷会使 C3 的产物消费边界检查失效。

修复在 E11-B 读取固定报告前调用既有 load_artifact()。请求未提供哈希时保留旧请求支持。schema、报告类型和目标提交检查继续执行。接口新增可选字符串字段 fixed_report_sha256，其值为 fixed_report 文件字节的 SHA-256；不一致返回 ARTIFACT_HASH_MISMATCH，且不生成修复补丁。

服务器证据为 work/e13-C2-C3-qnhtm712/C3。回归测试覆盖执行入口的哈希拒绝、匹配哈希继续执行及旧请求继续执行。相关文件为 labs/e11e12/pipeline.py 和 labs/e13e14/tests/test_b06_regressions.py。C3 通过补丁前的哈希拒绝，C1 验证正常输入可修复。该缺陷修复已在个人分支，待 PR 审查与目标 CI。

## Docker Hub 访问超时阻断 DRAFT

服务器首轮 C1 在拉取摘要固定的 Python 基础镜像时超时，结果为 DRAFT_FAILED，未产生修复阶段。原始失败目录为 work/e13-C1-a06-to-b06-20261119-111355。

修复在 DRAFT 的 Docker build 参数中加入同摘要的 DaoCloud 镜像站上下文映射。两轮构建的实际参数保存在各自 command 中，候选文件和 A06 项目提交仍以原始字节/完整 SHA 追溯。该适配依赖 DaoCloud 可达，仅针对匹配的摘要固定 Python 3.13-slim 基础镜像。

服务器成功目录为 work/e13-C1-a06-to-b06-mirror-20261119-111705。新增回归测试验证两轮构建的上下文映射、原摘要、参数记录，以及其他基础镜像的行为。相关实现位于 labs/e11e12/vendor/draft/autobuild.py。镜像站是环境适配，发布时需记录该外部下载依赖。

## Secret 扫描把 JSON 读取表达式误报为字面密钥

历史扫描在 scripts/verify-anonymous-image-pull.py 的 JSON 读取表达式上产生一条密钥赋值命中，脱敏值为 json***，导致扫描退出 1。原始记录为 work/e13-C6-plkkrwjb/source-history-image-scan.txt。

修复只在密钥赋值这一类别中排除未加引号的 json.load()/json.loads() 读取表达式。引号包裹的字面字符串、普通 Token、JSON 内容中的明确 Key 仍受对应模式检查。该扫描器是正则启发式检测器，扫描结论对应实际检查范围。

服务器复扫退出 0，记录为 work/e13-C6-plkkrwjb/source-history-image-rescan.txt。现场 7 项输入测试及新增的 3 个自动化测试方法覆盖误报和保留检出能力。相关实现为 labs/e11e12/environment/scripts/secret_scan.py，自动化测试为 labs/e13e14/tests/test_b06_regressions.py。
