## E9 扩展：重复 MD 去重

我把报告里的 MISSING main.o/config.h 复制了一次，让同一条记录出现两次。预期是只补一次 config.h，plan 也只有一项，原 Makefile 不变。

原实现会照着报告逐条追加，所以三种风格都会加两次。我的改动是在 patch() 中增加 seen 集合，用 (target, dependency) 作为键，处理过的同一条依赖直接跳过。用完整的二元组是为了保留“不同目标缺同一个文件”和“同一目标缺不同文件”这两种情况。

|风格|修复前：添加次数 / plan 数量|修复后：添加次数 / plan 数量|原文件字节不变|
|---|---|---|---|
|direct|2 / 2|1 / 1|是|
|macro|2 / 2|1 / 1|是|
|mixed|2 / 2|1 / 1|是|

修复后三份补丁都能应用到副本，构建输出 1，重检没有 MISSING，unused.h 和原配方保留。修复前后的输入、Patch、plan、字节快照和日志放在 `work/e9-duplicate-md/before-fix/`、`after-fix/`。

我在 Student241880258E9Tests 中增加了两项测试：一项检查三种风格的重复 MD、原文件和输入报告是否保持不变；另一项加入不同目标、不同依赖的交错重复记录，检查没有误删应该保留的修复。代码在 `labs/e8e10/test_profile.py`，复现脚本为 `labs/e8e10/student_241880258_e9.py`。
