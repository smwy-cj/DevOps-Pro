# ADR：仅有冗余依赖时返回空修复

- 学号：241830179。

## 问题与决策

依赖报告仅包含 REDUNDANT 时，需要明确补丁生成器的行为。
本次采用“保留所有声明，返回空 diff 和空 plan，原 Makefile 字节不变”的策略。
现有 patch() 通过跳过非 MISSING 项实现此行为，因此本次新增测试和证据导出，保留现有修复逻辑。

## 备选方案

| 方案 | 影响 | 选择 |
|---|---|---|
| 自动删除 REDUNDANT | 可能删除其他配置下需要的依赖声明 | 不采用 |
| 保留原声明并返回空操作 | 符合仅修复缺失依赖的范围，便于调用方跳过应用步骤 | 采用 |
| 对 REDUNDANT-only 抛出异常 | 增加正常空操作场景的处理成本 | 不采用 |

## 证据

通过真实 fixture 和 scan() 构造非空 REDUNDANT-only 报告，精确匹配 main.o/unused.h。
direct、macro、mixed 三种声明形式均通过：补丁为 0 字节、plan 为 []、前后原始字节一致、冗余依赖保留。
结果保存在 `work/241830179-20261103T141400Z-223866/B-member2-e8/`。
完整 11 项单元测试通过，扩展测试和持久证据导出共用同一验收函数。

## 影响与限制

调用方将空补丁视为无修复操作，跳过 git apply。报告可能继续保留 REDUNDANT 项。
冗余判断受当前构建配置和观察范围限制。本次未扩大检测器语义或 Makefile 语法支持范围。
